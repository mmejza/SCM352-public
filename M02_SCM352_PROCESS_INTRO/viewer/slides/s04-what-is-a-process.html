What Is a Process?
Three elements — one entity that moves through all three

INPUT

Raw materials, customers, orders — the flow unit in its initial state

TRANSFORMATION

Resources (people, machines, space) that act on the flow unit

OUTPUT

The flow unit in its finished state — delivered, sold, or discharged

Flow Unit

The specific entity we track as it moves from input to output. Every process metric — inventory, flow rate, flow time — is defined relative to the flow unit you choose.

Operations managers measure and improve processes by measuring what happens to the flow unit at each stage.
