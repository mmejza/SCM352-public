Process Scope
The same operation — different scope — different metrics
Definition

Scope = the set of activities and resources included in your process analysis. Scope determines which inventory, flow rate, and flow time you are measuring.

Broad Scope

Includes all stages end-to-end. I = all flow units in the entire system. Appropriate for: executive decisions, system-wide capacity planning.

Narrow Scope

Includes one stage or department. I = flow units in that stage only. Appropriate for: local efficiency, stage-specific bottleneck analysis.

Diagnostic Question

Before drawing any process diagram — ask: whose decision is this analysis meant to support? The answer determines the correct scope.
