Key Formulas

Chapter reference — LO3-5

Time to Produce Q Units

Non-empty system:
Time = Q × cycle time

Empty system (worker-paced):
Time = Tempty + (Q − 1) × cycle time

where Tempty = sum of all processing times
(use the longest time for parallel steps)

Cycle time = 1 ÷ flow rate (in matching time units)
