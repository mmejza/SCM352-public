Process Analysis

Module 2 gave you three metrics and the formula that connects them. This module opens the black box. You will break a process into steps, assign a capacity to each step, find the step that limits the whole process, and calculate exactly how long it takes to complete any quantity of output. These tools tell you where to invest when you want more throughput — and why a faster machine sometimes does nothing for how many units you produce per hour.

This module is built around one central question: which step in a multi-step process determines how many units you can produce per hour? Finding that step — and only that step — is what process analysis is about. Before recommending any operational improvement, the first question is always the same: is this the bottleneck?
