From Measuring to Managing
Module 02 gave you the metrics — Module 03 opens the black box

Module 02 — Measuring

Given a process, calculate I, R, T using Little's Law. The process was treated as one black box — one flow rate in, one out.

Module 03 — Managing

Break the black box into steps. Find which step limits the whole system. Calculate where adding resources actually improves output.

The Central Question

Where in the process should you invest? Adding workers to the wrong step wastes money. Adding speed to the wrong step changes nothing. Process analysis tells you which step is the right one.

R from Little's Law comes from somewhere — it is the minimum capacity among all resources in the process, constrained by demand. This module shows you how to find that minimum.
