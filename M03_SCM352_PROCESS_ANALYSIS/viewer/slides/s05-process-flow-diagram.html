Process Flow Diagram: The Three Elements
Every process flow diagram uses exactly these three conventions

☐ RECTANGLE

Resource — the worker, machine, or station that transforms flow units. Label with name and number of workers (m).

Example: Baggage Scanner (m=1)

△ TRIANGLE

Inventory — flow units waiting to be processed. Draw wherever flow units can accumulate before a resource.

Example: Travelers waiting for baggage scanner

→ ARROW

Flow direction — upstream to downstream. Arrows show the path of the flow unit through the process.

Splits at branch points (e.g., rework or rejection)

ElementDrawn WhenCommon Error
RectangleA resource actively processes flow unitsListing workers as rectangles instead of the station itself
TriangleFlow units can physically wait before a resourceOmitting triangles between stations
ArrowFlow units move from one element to the nextDrawing arrows without labeling the flow unit
