Worker-Paced vs. Machine-Paced
The difference changes both the diagram and the time-to-Q formula

Worker-Paced

  • Each station operates at its own pace
  • Flow units can accumulate between stations
  • Triangles appear between stations
  • First unit waits at each triangle before being served

Example: Subway sandwich assembly · Hospital triage · Fulfillment center

Machine-Paced

  • All stations move at the same rate (conveyor belt)
  • Flow units cannot accumulate between stations
  • No triangles between stations
  • One triangle only: at the entry to the entire line

Example: Automotive assembly plant · Bottling line · Conveyor production

Why It Matters for Calculations

In a worker-paced process, the first unit through an empty system waits at each station sequentially — processing time through empty = sum of all station processing times. Lecture Segment 1 shows why this distinction changes the time-to-Q formula.
