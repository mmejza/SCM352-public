The Four-Step Procedure
Each step depends on the prior — a chain, not a checklist

Step 1 — Find the bottleneck

Calculate capacity of each resource (C = m ÷ PT). The resource with the lowest capacity is the bottleneck. Process capacity = bottleneck capacity.

Step 2 — Find the flow rate

Flow rate = min{demand rate, process capacity}. If demand > capacity → capacity-constrained. If demand < capacity → demand-constrained.

Step 3 — Calculate utilization

Utilization of each resource = Flow rate ÷ Resource capacity. Bottleneck = 100%. All others < 100% when capacity-constrained.

Step 4 — Calculate cycle time

Cycle time = 1 ÷ Flow rate. This is how long between successive completions at steady state. Units: time per flow unit.

If Step 2 is wrong, Steps 3 and 4 are both wrong. Always confirm constraint type before calculating utilization or cycle time.
