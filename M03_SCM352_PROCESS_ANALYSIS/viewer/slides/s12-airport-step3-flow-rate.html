Airport Security — Step 3: Flow Rate
Flow rate = min{demand rate, process capacity}
Flow Rate = min{ 56, 40 } = 40 travelers/hr

Capacity-Constrained ← This case

Demand (56) > Process capacity (40). The process cannot keep up. Travelers accumulate before the baggage scanner. Flow rate = process capacity = 40/hr.

Demand-Constrained (other case)

If demand were only 30/hr: Flow rate = min{30, 40} = 30/hr. Process has spare capacity. No travelers wait. Flow rate = demand rate.

The Classification Changes Everything Downstream

In a demand-constrained process, flow rate ≠ process capacity. If you set flow rate = 40 when demand is 30, your utilization calculations will be wrong — bottleneck will show 100% when it should show 75%. Always show the min{} setup.
