The Non-Bottleneck Speed Trap
Making a non-bottleneck faster never increases process capacity
Common But Wrong

"If we upgrade Station 1 to run twice as fast, we'll double our output." Only if Station 1 is the bottleneck. If it isn't, upgrading it does nothing.

ScenarioBefore UpgradeAfter UpgradeChange in Capacity
Station 1 upgraded (non-bottleneck) min{120, 80, 40} = 40/hr min{240, 80, 40} = 40/hr None
Station 3 upgraded (bottleneck) min{120, 80, 40} = 40/hr min{120, 80, 80} = 80/hr +40/hr
Decision Rule

Before recommending any speed improvement or investment, ask: Is this the bottleneck? If no — the recommendation does nothing for throughput. If yes — calculate the new process capacity after the improvement and identify the new bottleneck.
