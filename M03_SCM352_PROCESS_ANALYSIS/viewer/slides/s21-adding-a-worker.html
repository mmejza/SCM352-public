Adding a Worker: The Right Step
Always add to the bottleneck — and identify the new one
Using the Airport Security Example

Bottleneck = Station 3 (Baggage Scanner, 1 machine, 1.5 min, 40/hr). Process capacity = 40/hr. Two options for adding a resource:

OptionStation TargetedNew Station CapacityNew Process CapacityChange?
Add officer to Station 1 Non-bottleneck (120→240/hr) 240/hr min{240, 80, 40} = 40/hr None
Add machine to Station 3 Bottleneck (40→80/hr) 80/hr min{120, 80, 80} = 80/hr +40/hr
New Bottleneck After Adding to Station 3

Station 3 (80/hr) now ties with Station 2 (80/hr) — both are bottlenecks. Station 1 (120/hr) still has slack. Every time you relieve a bottleneck, the next-tightest step becomes the new constraint.
