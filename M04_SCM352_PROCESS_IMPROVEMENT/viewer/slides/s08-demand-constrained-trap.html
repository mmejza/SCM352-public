Demand-Constrained: Flow Rate Trap
Same process · same stations · demand = 2 claims/hr (not unlimited)
Wrong Approach

"Process capacity = 3/hr, so flow rate = 3/hr."

→ CT = 20 min  ·  Util = 75%

These numbers are wrong because you ignored demand.

Correct Approach

Flow rate = min{ demand, process capacity } = min{ 2, 3 } = 2 claims/hr

CT = 30 min  ·  Util = 50%

Workers are idle for half the available time.
