Takt Time — Two Forms
The pace demand sets — both formulas must produce the same answer
Form 1 — Rate Form
Takt time = 1⁄demand rate

Use when: demand is given as a rate (units per hour, per day, etc.)

Example: Demand = 20 units/hr
→ Takt = 1/20 hr = 3 min/unit

Form 2 — Available-Time Form
Takt time = Available time⁄Required output

Use when: demand is given as a quantity per shift or per period

Example: 160 units per 8-hr shift
→ Takt = 480 min ÷ 160 = 3 min/unit

Verification Rule

Both forms applied to the same problem must yield the same takt time. A mismatch means a unit conversion error — check that available time and demand rate use consistent time units.
