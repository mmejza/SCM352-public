From One Flow Unit to Many
Modules 03–04 assumed one type, one path. That assumption just broke.
Modules 03–04 — One Path
  • ✓  Every unit visits every resource
  • ✓  Capacity = m ÷ processing time
  • ✓  Bottleneck = lowest-capacity resource
  • ✓  One flow rate for the whole process
Module 05 — Many Paths
  • +  Types defined by the path they take
  • +  Demand matrix maps who goes where
  • +  Bottleneck = highest implied utilization
  • +  A flow rate for every flow unit type
The Central Question of Module 05

When different units take different paths, which resource is actually the most constrained? The slowest station is no longer guaranteed to be the answer.
