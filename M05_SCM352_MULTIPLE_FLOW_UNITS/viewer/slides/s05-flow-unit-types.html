Flow Unit Types & the Demand Matrix
Types are defined by the path they take — not by what they look like
Definition

A flow unit type is a group of units that follow the same routing. The demand matrix records the demand each type places on each resource: rows = resources, columns = types.

Why the Zeros Matter

A zero is a routing statement: type j never visits resource i. A wrong non-zero adds phantom demand — and every calculation after it inherits the error.
