Flow Rate Rules
Check the threshold first — then apply exactly one rule
Max IU ≤ 100% → Demand-Constrained
Flow rate (each type) = demand rate

Every arriving unit is served. No division. No rationing.

Max IU > 100% → Capacity-Constrained
Flow rate (type j) = demandj ÷ max IU

Demand is rationed proportionally — the same divisor applies to every type.

Two Things to Notice

1  The constraint check comes before any flow rate calculation — applying the divide rule to a demand-constrained process is the single most common error in this module.   2  One bottleneck rations all types at once: if max IU = 1.25, every type flows at demand ÷ 1.25.
