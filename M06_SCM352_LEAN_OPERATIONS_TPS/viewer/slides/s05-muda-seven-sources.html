Seven Sources of Muda
Applied to service and knowledge-work contexts
Waste TypeCore DefinitionService / Knowledge-Work Example
Overproduction Producing more than needed, before it's needed Generating a full financial report when only a summary was requested
Waiting Resource available but no work arriving Physician idle between patient appointments due to scheduling gaps
Transportation Moving materials or information without adding value Routing a form through 4 approvals when 2 are sufficient
Overprocessing Doing more work than the customer requires Re-entering data already captured in a different system
Inventory (WIP) Unprocessed items queued between steps Emails awaiting response; claims awaiting adjuster assignment
Motion Worker movement that doesn't transform the product Searching for a file that has no fixed digital location
Defects Errors requiring rework or correction Incorrect diagnosis code requiring claim reprocessing
NVA-Necessary — The Exception

A step that adds no customer value but is required by law, regulation, or safety. Example: FDA documentation before pharmaceutical release. "Required by management policy" does not qualify — only regulatory or safety mandates.
