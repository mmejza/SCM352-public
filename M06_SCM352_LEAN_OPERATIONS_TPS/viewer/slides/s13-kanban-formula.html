Kanban Card Sizing — How Many Containers?
Authorizing exactly the inventory needed — and no more
K = (D × LT + SS) ⁄ C
Variables

D = daily demand rate (units/day)

LT = replenishment lead time (days)

SS = safety stock (units) — buffer for LT uncertainty

C = container size (units/container)

K = number of kanban containers authorized

What D × LT Means

Demand during the replenishment window — the units the system must cover while waiting for the next delivery to arrive.

This is the floor. Safety stock adds the buffer.

What Kanban Authorizes

The system authorizes exactly K containers. When a container is emptied, the kanban card travels upstream as a replenishment signal.

No more than K containers are ever in the system. This is what makes kanban a pull signal, not a push instruction.

Safety Stock Tradeoff

SS > 0 protects against LT variability. SS = 0 maximizes inventory efficiency — and maximizes stockout risk if LT extends unexpectedly.
