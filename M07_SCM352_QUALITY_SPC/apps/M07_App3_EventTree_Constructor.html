AND Logic — Fragile
A defect reaches output if ANY stage fails. Each stage must succeed independently. Failure rates multiply against good output.
OR Logic — Robust
A defect reaches output only if ALL checks miss it. Each check is a safety net. Miss rates multiply to find P(defect).
