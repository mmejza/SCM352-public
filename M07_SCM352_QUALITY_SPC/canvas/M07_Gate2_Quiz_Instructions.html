Key Formula Reminders

Process Capability: Cp = (USL − LSL) / (6σ̂) — the denominator is 6 times sigma, not sigma alone.

X-bar ESD: ESD(X̄) = σ(all parts) / √n — use the standard deviation of all individual measurements, NOT the standard deviation of the computed sample means. The n is the sample size within each period, not the number of periods.

p-chart ESD: ESD = √(p̄ × (1 − p̄) / n) — the entire expression p̄(1−p̄)/n is under the square root. Divide by n before taking the square root.

p̄ (centerline): p̄ = (total defects across all periods) / (total items inspected across all periods). Do NOT average the per-period proportions.

Event trees: AND-logic → P(Good) = multiply P(each step succeeds); OR/robust-logic → P(defect reaches output) = multiply P(each check misses).

Auto-Grading and Answers

All questions are auto-graded by Canvas. Fill-in-the-blank items use exact-match scoring — enter numerical values exactly as the question specifies (e.g., three decimal places for Cp, five decimal places for ESD(p)). Multiple-choice items are all-or-nothing.

For numerical fill-in-the-blank answers: Enter the number only (e.g., 1.333 not Cp = 1.333). If the question says "round to 3 decimal places," enter 3 decimal places exactly. For control-limit decisions, enter in control or out of control as shown in the question prompt.

For Q5 (variable classification): Enter exactly input, environmental, or outcome for each blank. Spelling must match. The key distinction is management control — an input is something management can set; an environmental variable is external to management control; an outcome measures process output quality.

No partial credit is available for fill-in-the-blank blanks — each blank is scored as correct or incorrect. There is no partial credit for multiple-choice items. Grade appeals are resolved using the module's answer key and review notes document.
