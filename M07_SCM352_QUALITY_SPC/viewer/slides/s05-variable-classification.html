Classifying Process Variables
Three types — the distinction determines which tool to use and where to look when things go wrong
INPUT VARIABLES

Under management control

Management can set or change these directly.

Examples: number of staff scheduled · machine speed setting · quality check frequency · raw material batch selection

→ Changing input variables is how management improves the process

ENVIRONMENTAL VARIABLES

Outside management control

Affect outcomes but management cannot set them.

Examples: ambient temperature · humidity · supplier delivery quality · seasonal demand

→ Management can only monitor or mitigate these

OUTCOME VARIABLES

Measure quality of process output

Vary as a result of the process; management influences but doesn't directly set them.

Examples: fill weight · error rate · handle time · proportion defective

→ What the control chart monitors and what Cp evaluates

The Decision Rule

Can management SET the value of this variable? → Input. Does it vary outside management's control but affect the outcome? → Environmental. Does it measure what the process produces? → Outcome. Gate 2 Q5 applies these categories to 8 novel variables.
