p-Chart — Construction Formulas
For binary outcomes: defective or not · proportion defective per period
p = (# defective in period) / n
Per-period proportion defective · n = items inspected per period
p̄ = (total defects, all periods) / (total items inspected, all periods)
Centerline — do NOT average the per-period p values · compute from raw totals
ESD(p) = √(p̄ × (1 − p̄) / n)
The entire expression p̄(1−p̄)/n is under the square root — divide by n BEFORE taking √
UCL = p̄ + 3 × ESD(p)     LCL = p̄ − 3 × ESD(p)
If LCL is negative → set LCL = 0 (a proportion cannot be negative)
Two Critical Errors to Avoid

Error 1 — p̄ from averages: Averaging the 8 daily p values gives a different (wrong) number than total defects / total items when periods have equal sample sizes. Always compute from totals.

Error 2 — ESD formula: √(p̄(1−p̄)) / n is wrong. √(p̄(1−p̄)/n) is correct. The division belongs inside the radical. If your ESD is larger than p̄, you made this error.
