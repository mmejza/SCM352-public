The SPC 4-Step Framework
Capability → Conformance → Investigate → Eliminate · in that order
1
Capability

Compute Cp. Is the process capable of meeting the specification in principle?

Tool: Cp index

If Cp < 1.00: fix the process before deploying a control chart

2
Conformance

Deploy a control chart. Is the capable process behaving consistently over time?

Tools: X-bar chart, p-chart

If in control: continue monitoring. If out of control: go to Step 3.

3
Investigate

Find the assignable cause that triggered the out-of-control signal. Do not ignore it.

Tools: Fishbone diagram, process interviews

If cause found: go to Step 4. If not found: monitor more closely.

4
Eliminate

Remove the root cause. Implement process change. Return to Step 2 monitoring.

Tools: Pareto chart, process redesign

Document the change. Update control chart baseline if the process has improved.

The Ordering Matters

Do not deploy a control chart on an incapable process — it generates false urgency. Capability check (Cp) always comes first. Control charts only make sense once capability is confirmed. The Case Analysis works through Steps 1–4 sequentially across its five parts.
