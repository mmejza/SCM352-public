Classification Depends on Process Context
Same physical object — three different inventory types in one day
The Plastic Pellet Supply Chain

A food-grade plastic pellet leaves a grain supplier, travels to a plastics manufacturer, is molded into a food container, and ships to a food packaging company. At each stage, the classification changes — even though the object is the same.

Stage / Location Classification Why — from which process perspective?
Railcar in transit (supplier → manufacturer) Pipeline inventory Neither firm has it on-hand; in transit between entities
Manufacturer's raw material storage room Raw material Manufacturer's transformation process has not yet started
Inside the injection molding machine (being heated) Work-in-process (WIP) Manufacturer's transformation has begun but is not complete
Finished pellet leaving the manufacturer Finished goods Manufacturer's process is complete; ready for sale/shipment
Same pellet arriving at food packaging company Raw material again The packager's process has not yet started — reference process changed
Key Rule

Classification is not determined by the physical state of the item — it is determined by where the item sits relative to the reference process. Specify the process first; then classify.
