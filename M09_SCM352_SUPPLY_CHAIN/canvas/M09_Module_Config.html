Step 2a — Canvas Embed Procedure (Apps, Slide Viewer) and Gate 1 Cooldown

Embedding HTML files in Canvas pages

Use for items 6, 7, 8, 9 (slide viewer and all three apps)

Canvas pages do not natively render external HTML files. Each app and the slide viewer must be embedded via an iFrame inserted through the Canvas Rich Content Editor HTML source view.

<p><iframe src="PASTE_FILE_URL_HERE" width="100%" height="700" style="border:none;border-radius:8px;" allowfullscreen></iframe></p>

Steps: (1) Upload the HTML file to Canvas Files → M09_Apps or M09_Viewer folder. (2) In Canvas Files, click the file → Copy Link. (3) In the Canvas page editor, click HTML Editor (source view). (4) Paste the iFrame template above and replace PASTE_FILE_URL_HERE with the copied file URL. (5) Set height to 700 for apps and 760 for the slide viewer. (6) Switch back to Rich Content Editor view to confirm the embed renders before saving.

Gate 1 Retake Cooldown — Canvas Limitation

Must configure manually; Canvas does not enforce 24-hr gap automatically

Canvas allows you to set "allowed attempts" but does not natively enforce a 24-hour cooldown between attempts. The cooldown must be managed through Quiz Settings plus a course announcement.

1In Quiz Settings → Attempts Allowed: 2. Canvas will allow students to retake immediately after the first attempt without a true cooldown.
2Workaround: Post a course announcement on Day 1 stating: "Gate 1 has 2 attempts. You must wait 24 hours between attempts — this is enforced by honor code, not Canvas. Do not use your second attempt immediately after failing the first."
3If a student uses both attempts on Day 1 (Canvas will allow this), do not grant additional attempts. The honor-code policy governs. Check quiz attempt timestamps if a student disputes a score — both attempts will show a submission date.
Step 3 — Gate 2 Version Reference (Q1 and Q3)
ℹ️
Q1 (Inventory Turns) and Q3 (Postponement) are parameterized. Configure each as a Canvas Question Group drawing 1 question from 4 versions at random. See gates/M09_Gate2_Quiz_Reference.md for full question text. Canvas assigns one version of each per student attempt.

Question Groups setup — step-by-step

Do this inside the Gate 2 Quiz in Canvas → Questions tab

1Open Gate 2 Quiz → Edit → Questions tab.
2Click + New Question Group. Name it "Q1 — Inventory Turns (Pick 1 of 4)". Set "Pick 1 question" and "2 pts each question" (Canvas may not enforce pts here; verify point value per version matches Q1's point allocation).
3Add 4 questions inside the Q1 group — one per version (A, B, C, D). Use the question text from M09_Gate2_Quiz_Reference.md rows Q1-A, Q1-B, Q1-C, Q1-D. All 4 questions must be inside the group.
4Repeat for Q3 — Postponement (Pick 1 of 4). Same process: new group, 4 version questions inside, pick 1 randomly.
5Questions Q2, Q4–Q8 are non-parameterized — add them as standard questions (not inside a group) in sequential position.
⚠Use Student View to verify that Canvas randomizes Q1 and Q3 correctly — reload the quiz preview several times to confirm students see different versions. Confirm total point count before publishing.

Step 4 — During-Module Monitoring

Weekly monitoring actions — 30 min total

Day 3
Pull Gate 1 completion report. The four bullwhip root causes (Section 11.3) and the MTO decoupling point concept (Section 11.4) are entirely absent from slides and narration — chapter-exclusive content. Students with 0 Gate 1 attempts by Day 3 will very likely fail G1-Q2, G1-Q3, and G1-Q4. Send a targeted individual nudge, not a class-wide message.
Day 4
Scan Discussion initial posts for naming violations and prohibited firms. Check the first two sentences of each post for company name mentions (10-pt deduction) and for prohibited firms (Zara, Dell, Amazon, HP, Riverside Health System, GloveCo, or any firm from Chapter 11 textbook examples). Do not reply publicly — message the student privately to repost.
Day 6
After Gate 2 closes: Export quiz statistics. Watch for Q1 COGS/revenue substitution (turns > 2× expected value for a version). Watch for Q3 decoupling point direction errors (students writing "decoupling point moves downstream" = wrong direction). Watch for Q6 root cause identification that names "bullwhip effect" as the cause rather than selecting one of the four Chapter 11 root causes.
Post-module
Grade Discussion initial posts after following module closes. Batch by criterion (all Part 1 responses, then all Part 2, etc.) rather than by student for efficiency. Apply the 10-pt naming penalty after totaling the rubric score — not as a rubric criterion.
