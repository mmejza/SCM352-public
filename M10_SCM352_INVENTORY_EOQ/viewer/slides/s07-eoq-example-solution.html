EOQ Example — Solution
R = 4,800 · K = $75 · h = $6.00
Part (a) — Compute Q*

Q* = √(2 × 75 × 4,800 / 6.00) = √(720,000 / 6.00) = √120,000 = 346.4 ≈ 346 units

Part (b) — Order Frequency

Orders/year = R/Q* = 4,800/346 = 13.9 orders/year

Time between orders = 52/13.9 = 3.7 weeks

The firm should reorder approximately every 3–4 weeks.

Part (c) — Current Batch = 200

200 < Q* (346) → ordering too frequently

Current: R/200 = 24 orders/year vs. optimal 13.9 orders/year

Fix: increase batch size toward 346 to cut ordering cost without unduly raising holding cost

Confirmation Check at Q* = 346

Ordering cost = K × (R/Q*) = 75 × 13.87 = $1,040/year  ·  Holding cost = h × (Q*/2) = 6.00 × 173 = $1,038/year

Ordering ≈ Holding ✓ — confirms Q* is the balance point
