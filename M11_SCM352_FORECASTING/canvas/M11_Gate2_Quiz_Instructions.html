Formula Quick Reference — Forecasting Metrics

Moving Average (Q1)
MAt = (Dt + Dt-1 + … + Dt-n+1) / n
Sum the n most recent actual demand values and divide by n. Forecast for the next period.
Exponential Smoothing (Q2)
Ft+1 = α·Dt + (1−α)·Ft
α given in your question · Use your computed Ft in each next step (not the actual demand) · Round to 2 decimal places
MAD (Q3)
MAD = Σ|Dt − Ft| / n
Use absolute value (no signs) in the numerator · Divide by the number of periods with errors
Bias (Q3)
Bias = Σ(Dt − Ft) / n
Keep the signs — positive errors and negative errors do NOT cancel in MAD but DO cancel in Bias · Positive Bias = under-forecast
MAPE (Q6)
MAPE = [Σ(|FEt| / Dt)] / n × 100%
Denominator is actual demand Dt (not the forecast) · Compute per-period % first, then average · Express as a percentage
Error = Actual − Forecast
Positive error = actual > forecast = under-forecast
Negative error = actual < forecast = over-forecast
This convention is used in every question — error is always computed as Actual minus Forecast, not the reverse.

Critical Q3 trap: MAD vs. Bias
MAD uses absolute values of errors in the numerator — all values are positive before you sum. Bias uses signed errors — positive and negative errors are added together. Using absolute values for Bias is the most common error on this quiz. See the formula card above for the exact difference.
Essay questions (Q4, Q7) and Data Analysis (Q8)
All sub-parts must be answered. Use Chapter 15 terminology: "moving average," "exponential smoothing," "smoothing parameter α," "forecast combination," "Delphi method," "analogical forecasting," "anchoring," "forecast gaming," "overconfidence." Generic definitions without application to the specific question's scenario earn partial or no credit.
Q6 MAPE trap: denominator is actual demand
Each period's APE = |Error| / Actual Demand × 100%. Do not divide by the forecast. Dividing by the forecast produces a different (and incorrect) result. Compute per-period APEs first, then average them.
