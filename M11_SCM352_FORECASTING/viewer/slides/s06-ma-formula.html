The Moving Average Formula
Equal weight on the n most recent actual demand observations
MA(n) = ( Dt + Dt−1 + · · · + Dt−n+1 ) / n
Variable Definitions

MA(n) — forecast for the next period

n — window length (number of periods included)

Dt — actual demand in the most recent period

Dt−n+1 — actual demand n periods ago (oldest in window)

The n Trade-Off

Large n (e.g., 8–12 weeks): smooths noise; good for stable demand. Lags badly when a true trend emerges.

Small n (e.g., 2–3 weeks): tracks trend quickly. Overreacts to random spikes.

Common Error

Including the current period's forecast in the window. Use only actual observed demand values — Dt through Dt−n+1.
