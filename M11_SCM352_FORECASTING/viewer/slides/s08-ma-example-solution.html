Moving Average — Solution
Actual Week 7 = 118 units
3-Week MA (Weeks 4–6)

= (110 + 108 + 115) / 3

= 333 / 3 = 111.0 units

Error = 118 − 111.0 = +7.0 units

4-Week MA (Weeks 3–6)

= (98 + 110 + 108 + 115) / 4

= 431 / 4 = 107.8 units

Error = 118 − 107.8 = +10.2 units

Interpretation

3-week MA was more accurate this period — error of 7.0 vs. 10.2 units. For a demand series that is trending upward (weeks 1→6 show a generally rising pattern), the 3-week window is also preferred going forward: it gives more weight to recent, higher demand values and lags less behind the trend than the 4-week window, which averages in older, lower observations.

Note on Lag

Both forecasts are below actual demand (positive errors). This is the moving average lag: when demand trends up, any moving average consistently under-forecasts because the window center lags behind the current level.
