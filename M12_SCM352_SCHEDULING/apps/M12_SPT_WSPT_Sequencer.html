SPT / WSPT Sequencing Tool

LO12-3 · LO12-4 · Chapter 18.2–18.3
How to use this tool: Enter your jobs (processing time and optional weight), choose a sequencing rule, then click Compute Sequence. The tool shows the sorted order, flow time for each job, and summary metrics. Use it to check hand calculations before Gate 2.

Step 1 — Configure Jobs

Select number of jobs, then enter processing time and weight for each.

Step 2 — Choose Sequencing Rule

SPT ignores weights and sequences by processing time. WSPT uses the weight ÷ processing time ratio.

SPT: Sequence ascending by processing time. Minimizes average flow time. All weights ignored.
