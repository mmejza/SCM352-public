Formula Quick Reference — Scheduling Metrics

Flow Time
Fi = cumulative completion time from time zero
Not the job's own processing time. Sum all processing times up to and including job i in the sequence.
Lateness
Li = Fi − Di
Can be negative (early finish). Di is the due date/deadline. Negative lateness is not tardiness.
Tardiness
Ti = max(0, Li)
Always ≥ 0. No credit for being early. If lateness is negative, tardiness is zero.
SPT Rule
Sequence: ascending processing time
Minimizes average flow time. Ignores due dates and job weights.
WSPT Ratio
Ratio = Weight ÷ Processing Time
Sequence: descending ratio (highest first). Minimizes total weighted flow time.
EDD Rule
Sequence: ascending due date (earliest first)
Minimizes maximum lateness and maximum tardiness. Does not minimize average flow time.

Answering Each Question Type

Calculation questions (Q1, Q2, Q3)
State the rule or formula first, then sequence jobs, then build each column step by step. A correct final answer without shown work earns 50% maximum. Write every row of your performance table — do not skip steps or summarize intermediate values.
Critical Q1 trap: Tardiness ≥ 0
Tardiness = max(0, Lateness). If lateness is negative (the job finishes early), tardiness is zero — not the lateness value. There is no "negative tardiness." Entering a negative number in the tardiness column is a common error worth significant partial credit.
Data Analysis (Q5) and Essay questions (Q4, Q6)
All sub-parts must be answered. Use Chapter 18 terminology: "implied utilization," "bottleneck," "Theory of Constraints," "SPT," "LPT," "appointment interval," "overbooking," "no-show rate," "open-access scheduling." Generic answers without reference to the specific scenario earn partial or no credit.
Q5 bottleneck trap: invest at the bottleneck only
The most common Q5 error is investing in the resource with the lowest utilization to "balance" the system. Theory of Constraints says only bottleneck investments increase throughput. Investments at non-bottlenecks do not change the system throughput ceiling.
