Project Background — 10 Activities

Riverside Health System is replacing its legacy patient records system with a new Electronic Health Records (EHR) platform across all three campuses. The project involves 10 activities: A (project planning and vendor finalization), B (infrastructure build-out and server installation), C (vendor-led EHR software configuration), D (data migration and historical record conversion), E (integration testing — requires C and D complete), F (staff training — requires B and E complete), G (go-live readiness audit — requires D complete), H (pilot campus rollout — requires E, F, and G complete), I (issue remediation post-pilot — requires H complete), and J (full system cutover and sign-off — requires I complete).

The dependency structure above is the same for all four versions. Your version's duration values are shown in the activity table at the top of the Canvas quiz. Use those durations throughout all four parts.

Recommended scratch-paper sequence:
  1. List activities A–J, record your version's durations from the Canvas table.
  2. Draw the AON network (Start → A → {B, C} → ...); confirm merge points at E, F, H, and J.
  3. Forward pass: compute ES and EF for every activity (ES of A = 0; max rule at merge points).
  4. Record project duration = EF of J.
  5. Backward pass: compute LS and LF (LF of J = project duration; min rule at split points).
  6. Compute slack for every activity (Slack = LS − ES). Activities with slack = 0 are critical.
  7. List all paths and verify the critical path(s).

Part 4
Project Crashing — Minimum-Cost Duration Reduction
25 points total
Crashing context: Riverside's hospital board has set a hard contractual deadline 2 weeks earlier than the current CPM project duration. You must reduce project duration by exactly 2 weeks at minimum cost. A crash table will be provided in the quiz showing available crash time and crash cost per week for each crashable activity. Only critical path activities can reduce project duration. Apply the greedy minimum-cost approach: crash the cheapest critical activity first, then re-evaluate the critical path before proceeding.
5 pts 2 blanks Part 4a — Crash Candidates Ranking: From the crash table (provided in Canvas), list the two cheapest critical path activities to crash.
