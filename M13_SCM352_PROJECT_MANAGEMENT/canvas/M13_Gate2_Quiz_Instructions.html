CPM Formula Quick Reference

Forward Pass
EF = ES + Duration
ES of first activity = 0. For merge activities: ES = max(EF of all predecessors).
Backward Pass
LS = LF − Duration
LF of last activity = project duration. For split activities: LF = min(LS of all successors).
Slack
Slack = LS − ES
Activities with Slack = 0 are on the critical path. Slack can never be negative if calculations are correct.
Critical Path
Longest path from Start to End
Every activity on the critical path has Slack = 0. Two paths can tie — both are then critical.
Crashing
Crash cheapest critical activity first
After each crash step: re-check all path lengths. A new critical path may emerge — crash only shared activities from that point forward.
Delay Analysis
Extension = max(0, delay − slack)
If delay ≤ slack: project unaffected. If delay > slack: project extends by (delay − slack) weeks.
