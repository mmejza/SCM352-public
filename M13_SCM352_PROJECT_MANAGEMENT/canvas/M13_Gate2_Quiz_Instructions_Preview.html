How to Answer Each Item Type

Answering Each Item Type

Fill-in-the-Blank items (Q1–Q3, Q4b, Q5a)
Type your answer directly into each blank field. Canvas accepts common formatting variants for activity sequences (e.g., A-B-D-E-G-H or A,B,D,E,G,H). Work out your complete CPM table on scratch paper first — enter values only when you have the full table in front of you. For path names: list activity letters in order, separated by dashes or spaces.
Notation used in Q2 and Q3
Q2 asks for ECT (Earliest Completion Time = ES + Duration). Q3 asks for LCT (Late Completion Time) and ST (Slack Time = LCT − ECT). These match the notation in your textbook and lecture materials. LCT of the last activity equals the project duration; LCT of any activity with multiple successors equals the minimum LST of those successors.
Multiple Choice items (Q4c, Q4d, Q5b)
Select the single best answer. Q4c and Q4d test Gantt chart delay reasoning — read the network dependency note in the question carefully before choosing. Q5b tests the distinction between a technical dependency and a scheduling preference.
Multiple Answers item (Q4a only — select ALL that apply)
Q4a asks which activities are on the critical path. Select every activity with ST = 0 — this item is all-or-nothing. Selecting all correct options earns full credit; a partial or over-inclusive selection earns zero.
