Learning Objectives
Structure (LO13-1 to LO13-2) · Computation (LO13-3 to LO13-4) · Interpretation (LO13-5)
1
Build a dependency matrix from a project description: identify activities, classify predecessor relationships, and distinguish true dependencies from scheduling preferences
2
Construct an Activity-on-Node (AON) network from a dependency matrix, applying the rules for START/END nodes and activities with multiple predecessors
3
Perform a CPM forward pass to compute EST and ECT for every activity; identify the critical path as the longest path through the network
4
Perform a CPM backward pass to compute LCT and LST; compute slack (ST = LCT − ECT) for each activity; identify all critical activities
5
Read and interpret a Gantt chart: identify activity bars and slack bars, determine which activities are critical, and analyze the impact of an activity delay on project completion
