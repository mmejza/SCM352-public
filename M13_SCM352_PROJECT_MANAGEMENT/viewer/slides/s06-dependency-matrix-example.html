Worked Example — Restaurant Expansion
5 activities · Build the dependency matrix from the project narrative
Project Narrative

A restaurant group is opening a new location. Five activities are required:

  • Secure the lease for the new space.
  • Complete the kitchen buildout — requires the lease first.
  • Hire and train staff — requires only the signed lease; kitchen does not need to be done.
  • Install POS and technology systems — requires the kitchen to be built first.
  • Hold the grand opening — requires both staff training and POS installation to be complete.
Key Predecessor Decisions

Staff training (C) predecessor: Only A (lease) — not B (kitchen). Training can start as soon as the lease is signed. Adding B would extend the critical path unnecessarily.

Grand opening (E) predecessors: Both C (training) and D (POS). The opening cannot happen until staff are ready AND the system is running.
