CPM Forward Pass — Rules
Computes EST and ECT for every activity · Work left to right through the network
EST — Earliest Start Time

The earliest a job CAN begin, given all its predecessors are complete as fast as possible.

First activity: EST = 0

All others: EST = ECT of predecessor (or MAX of predecessors at a merge point)

ECT — Earliest Completion Time

The earliest this activity can finish, assuming it starts at EST.

ECT = EST + Duration

ECT of the last activity = minimum project duration.

The Merge Rule — MAX

When an activity has two or more predecessors, it cannot start until ALL predecessors are complete.

EST = max(ECT₁, ECT₂, …)

Take the maximum ECT across all predecessors — the binding constraint is the last one to finish.
