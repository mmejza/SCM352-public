CPM Backward Pass — Rules
Computes LCT and LST for every activity · Work right to left through the network
LCT — Latest Completion Time

The latest an activity CAN finish without extending the project deadline.

Last activity: LCT = ECT (project deadline)

All others: LCT = LST of successor (or MIN of successors at a split point)

LST — Latest Start Time

The latest an activity can BEGIN without pushing its LCT past the deadline.

LST = LCT − Duration

The backward pass starts from the right and works toward START.

The Split Rule — MIN

When an activity feeds two or more successors, its LCT is determined by whichever successor's start constraint is tightest.

LCT = min(LST₁, LST₂, …)

Take the minimum LST across all successors — the binding constraint is the most urgent downstream need.
