Backward Pass — The Split Calculation
At every split point, LCT = min of all successor LSTs
Why MIN — The Intuition

An activity at a split point must finish in time to let every downstream activity begin when it needs to. If successor B must start by week 3 and successor C must start by week 6, the split activity must be done by week 3 — the earlier of the two constraints.

The minimum LST of all successors is the deadline imposed on the split activity. Finishing later than this would prevent the most time-sensitive successor from starting on schedule.

The Most Common Error

Using MAX instead of MIN for a split point in the backward pass. Students who remember "MAX for merge" and apply it everywhere get the wrong LCT at split points.

Merge (forward pass): MAX — wait for the last predecessor.

Split (backward pass): MIN — must finish before the earliest deadline.

Restaurant Expansion — Activity A

A (Secure lease) feeds both B and C.

SuccessorLSTConstrains A?
B — Kitchen buildout3Yes
C — Train staff7Yes

LCT(A) = min(LST(B), LST(C)) = min(3, 7) = 3

LST(A) = LCT(A) − Duration(A) = 3 − 3 = 0

B's start constraint (week 3) is tighter than C's (week 7). A must finish by week 3 to keep B on schedule. If A slips past week 3, the kitchen buildout cannot start on time — extending the project.
