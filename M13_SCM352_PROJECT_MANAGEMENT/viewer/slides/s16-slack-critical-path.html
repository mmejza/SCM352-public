Slack Time + Critical Path
ST = LCT − ECT · Critical activities: ST = 0 · Non-critical activities: ST > 0
Slack Time — Definition
ST = LCT − ECT

ST = 0: Activity is critical. Any delay extends the project deadline by the same amount.

ST > 0: Activity can be delayed up to ST periods without affecting the project completion date. The delay "uses up" slack — if the delay equals ST, the activity becomes critical.

Equivalently: ST = LST − EST. Both formulas give the same result.

Identifying the Critical Path

The critical path is the chain of ST=0 activities that runs from START to END. It is also the longest path through the network (confirmed by the forward pass path durations).

To find it: List all activities with ST=0. Trace the sequence from START to END — activities connect if one is a predecessor of the next.
