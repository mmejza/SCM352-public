The 4-Tool Framework
From project description to execution control — what each tool adds

Dependency Matrix

Makes hidden activity relationships explicit. Forces the question: what truly must be done before this can start? Predecessor classification is where project schedules are made or broken.

LO13-1 · Produces: activity list + predecessor columns

AON Network

Translates the matrix into a visual flow map. Reveals path structure, merge points, and split points. Makes it possible to enumerate all paths and count them — a prerequisite for the CPM.

LO13-2 · Produces: network diagram showing topology

CPM Forward + Backward Pass

Computes minimum project duration; determines which activities can slip and by how much. The complete CPM table answers all three project management questions with precision.

LO13-3, LO13-4 · Produces: EST, ECT, LCT, LST, ST, critical path

Gantt Chart

Converts the CPM schedule into a control document. Shows each activity's position on a timeline with solid bars for duration and dashed bars for slack. Lets the project manager immediately see the impact of any reported delay.

LO13-5 · Produces: visual schedule + delay impact visualization

Project Management and the Riverside Case

In the Module 13 Case Analysis, Riverside Health System is implementing a new electronic health record system across the organization — a 10-activity project (Activities A through J) involving vendor selection, workflow analysis, EHR configuration, hardware procurement, data migration, staff training, and a phased go-live.

The dependency matrix makes the EHR implementation's activity relationships explicit. The forward and backward pass identify the true critical path — which is often not the path the project team assumes. The Gantt chart tells you, in real time, whether the implementation is on track and by how much a specific delay will push the go-live date.

These are the same tools that would have changed the outcome at Denver International Airport.
